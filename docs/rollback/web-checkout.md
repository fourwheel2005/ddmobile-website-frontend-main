# ปิด/เปิด การสั่งซื้อผ่านเว็บ (ตะกร้า · ซื้อเลย · ชำระเงิน)

> ไฟล์นี้มีเหมือนกันทั้ง 2 repo · เปลี่ยนเมื่อ 2026-10-03 — ร้านปิดการขายในแชท LINE แทนการชำระเงินบนเว็บ

## สถานะปัจจุบัน (ค่าเริ่มต้น = ปิด)

| จุด | ตอนปิด (ตอนนี้) | ตอนเปิด |
|---|---|---|
| หน้าเครื่อง | ปุ่ม **"ซื้อเครื่องนี้ · ทักแอดมินทาง LINE"** (สินค้าหมด → "สอบถาม/สั่งจอง" · ขายแล้ว → "สอบถามเครื่องอื่น" · ไม่มีราคา → "สอบถามราคา") | เพิ่มลงตะกร้า / ซื้อเลย |
| แถบล่างมือถือ | "ซื้อ · ทัก LINE" + "ผ่อนเริ่ม …" | ตะกร้า + ซื้อสด + ผ่อน |
| การ์ดสินค้า | "ดูเครื่อง →" | ปุ่มตะกร้าเล็ก |
| ไอคอนตะกร้า (Navbar) | โชว์เฉพาะคนที่ยังมีของค้าง | โชว์เสมอ |
| `/cart` | "ส่งรายการนี้ให้แอดมินทาง LINE" | ดำเนินการชำระเงิน |
| `/checkout` | พาไป `/cart` | ชำระเงิน |
| `POST /api/v1/orders` | 403 `WEB_CHECKOUT_DISABLED` (ไม่สร้าง/ไม่จองเครื่อง) | สร้างออเดอร์ |

ข้อความ LINE ที่พิมพ์รอให้: รุ่น · สี/ความจุ/สภาพ · รหัส (IMEI/SKU) · ราคา · Flash Sale ที่หน้าเว็บโชว์ ·
**โค้ดส่วนลดที่ดีที่สุดของลูกค้า** · ลิงก์หน้าเครื่อง (ตรงตัวเลือกที่เลือก) · ชื่อ/เบอร์ · กดแล้วนับสถิติ "บริการที่ลูกค้าสนใจ" (มือ 1 / มือ 2)

**ไม่กระทบ:** ออเดอร์ที่สั่งผ่านเว็บไปแล้ว (แนบสลิป · ติดตามพัสดุ · ขอคืนเงิน · รีวิว) · ผ่อนเครื่อง (ฟอร์ม + บัตรประชาชน) · ขายเครื่อง / ผ่อนบอลลูน · หลังบ้านจัดการออเดอร์เดิม

**สิ่งที่แอดมินต้องรู้ (business flow):**
- คูปองส่วนลด: ลูกค้าใช้เองบนเว็บไม่ได้แล้ว → โค้ดที่ดีที่สุดถูกแนบมาในข้อความ ให้แอดมินตรวจ/หักให้ในแชท
- โค้ดโปรโมชัน (ที่เคยพิมพ์ในหน้าชำระเงิน): ลูกค้าต้องพิมพ์บอกในแชทเอง · Flash Sale ที่หน้าเว็บโชว์อยู่ถูกแนบมาในข้อความแล้ว
- รีวิวสินค้าใหม่มาจากออเดอร์เว็บเท่านั้น → ช่วงนี้รีวิวใหม่จะเพิ่มช้าลง (รีวิวเดิมยังแสดงครบ)

## เปิดการสั่งซื้อผ่านเว็บกลับ (ไม่ต้องแก้โค้ด)

⚠️ **ต้องเปิดทั้ง 2 ฝั่ง และเปิด backend ก่อน** — ถ้าเปิดแค่หน้าเว็บ ลูกค้าจะกดชำระเงินแล้วเจอ 403

1. Backend: `.env` บนเซิร์ฟเวอร์ → `WEB_CHECKOUT_ENABLED=true` → `docker compose up -d --force-recreate app`
   ตรวจ: `docker exec ddmobilewebsite printenv WEB_CHECKOUT_ENABLED` ต้องได้ `true`
2. Frontend: Vercel → Environment Variables → `NEXT_PUBLIC_WEB_CHECKOUT` = `on` → **Redeploy** (ค่าถูกฝังตอน build)
3. ตรวจ: หน้าเครื่องมีปุ่ม "เพิ่มลงตะกร้า / ซื้อเลย" · สั่งซื้อทดสอบได้ถึงหน้าแนบสลิป

ปิดอีกครั้ง: ทำกลับด้าน — **ปิดหน้าเว็บก่อน** (ลบ `NEXT_PUBLIC_WEB_CHECKOUT` → Redeploy) แล้วค่อย `WEB_CHECKOUT_ENABLED=false`

## ย้อนโค้ดทั้งชุด (ถ้าต้องการลบความสามารถนี้ออกจริง ๆ)
ปกติ**ไม่จำเป็น** — สวิตช์ด้านบนคืนพฤติกรรมเดิมได้ครบ ถ้าจำเป็น: tag `pre-line-checkout` (ก่อนเปลี่ยน) / `line-checkout-v1` (หลังเปลี่ยน)
```bash
git checkout main && git pull
git revert --no-commit line-checkout-v1
git checkout HEAD -- docs/rollback/web-checkout.md      # เก็บบันทึกนี้ไว้
git commit -m "revert: checkout via LINE (keep notes)"
git push origin main
```
ลำดับ: backend ก่อน แล้วค่อย frontend (เหมือนการเปิดกลับ) · ไม่มี migration ฐานข้อมูลในชุดนี้
